# 小小探险家 · 英语课程书架

固定网址的三年级亲子英语互动课，按周浏览。从 2026-10-15 起，周一到周五每天一个新词，周六、周日各一次轻量派送复习；每个完整周是五个新词加两次周末活动。当前已备好 10-12～10-18 小花园周和 10-19～10-25 校园周；周五新词分别是 flower 与 box。

## 使用

从首页进入今日任务，历史课可重玩。周末派送只使用同周一到周五的五个词：听简单英语、选图片、送到中文标注的目的地，看场景发生变化。周六和周日使用同一套交互，但有不同的任务场景，不另加新词。课程以 Asia/Shanghai 的当天零点解锁；正常浏览不显示未来课内容，直接打开未来课链接也不能进入。放学后随时学习，不必等到 19:30。日期依赖设备时钟；公开静态源码中的未来数据不属于严格保密。

已存在的课程 ID、日期、内容和进度键保持不变，包括 10-08 block 原课和 10-09 方块复习。10-16、10-23 的原周五复习标为 supplemental，只作额外复习，不占每日默认任务，也不替换原进度。每课分别保存本机进度与笔迹，最初 block 的存储键保持不变。iPad 可用手指或 Apple Pencil 在画布写，也可选择纸笔，由妈妈确认。**目前没有手指手写自动识别。** 跟读也由妈妈确认，不上传录音或笔迹，不自动评分。换设备或浏览器不同步进度。

声音：固定 MP3，英语 Jenny / Aria、中文晓晓；右上角可试听、切换并保存全站声音偏好。录音失败时回退设备朗读，网页需要由用户点击后播放。

## 内容与维护

课程的唯一内容源：`dist/assets/lessons.json`。固定框架：`index.html` 课程书架、`lesson.html` 课程入口、`book-core.js` 日期/进度、`course-engine.js` 新词与复习互动、`delivery-engine.js` 周末派送；原始 block 保留 `app.js`。绘图是自绘 SVG，书写使用 Pointer Events。

后续备课与自动更新说明见 [COURSE_MAINTENANCE.md](COURSE_MAINTENANCE.md)。先读取已有词汇与日期，再追加下一完整周的五个新词及周六、周日两次派送。优先复用框架，只补课程数据和所需图片。

## 发布与校验

GitHub Pages 使用 GitHub Actions，发布 `dist`。工作流先校验课程和日期、运行完整交互流程测试，再生成并核对全部 MP3，成功后发布。语音使用开源 edge-tts，依赖在线服务；服务故障会阻止新版本发布。缓存可减少重复生成。

核心检查：`python scripts/validate_lessons.py`、`node tests/book-core.test.js` 与 JS 语法检查。完整交互测试：安装 jsdom 26.1.0，运行 `python scripts/generate_audio.py --list-texts > .audio-plan.json`，再运行 `node tests/course-flow.test.js`、`node tests/delivery-flow.test.js` 和 `node tests/voice-player.test.js`。

真实 iPad Safari 的手指、Apple Pencil 与音频体验需在设备上确认；DOM 流程测试不能替代真机检查。

听图环节标为“词义配图”，只核验声音与词义的对应，不作为相似发音辨别训练。新音节辨音内容尚未纳入本版。新词听音须等播放成功结束，取消、失败或静音均不会完成听音步骤。周末提示会标记辅助完成，不宣称掌握。

从今日 seed（2026-10-15）及以后新词起，“说一说”使用短流程：自然示范后留出跟读时间 → 一轮回声 → 隐藏拼写自行回忆 → 主动听示范核对 → 家长确认参与。没有固定倒计时或强制五遍，不录音、不做口型识别或发音评分；复用现有单词音频。旧课已经保存的 `said` 与完成星保持有效，不重置进度。

## 本地冒险成长（首版）

不同主题沿用同一位小探险家。每个关卡首次完成奖励 10 经验，每 100 经验升一级；这是冒险参与等级，不是英语能力或发音掌握评级。首次完整完成某主题的一课，留下主题印记。没有连续打卡惩罚，休息不扣分；重玩、重置课程和重复点击不重复奖励。

成长单独保存在 `little-explorer-growth-v1`。书架/课程载入及保存时，读取原有合法、已开放课程的 `completed` 标记，以课程 ID 加稳定关卡 ID 做并集迁移。保留 `little-explorer-block-v1` 和其他旧课键与内容，不凭预览未来课程发奖、不猜测已丢失的记录。旧数字关卡按 `growth.js` 中冻结映射迁移；以后不得通过插入或重排关卡改变这个映射。若需要新步骤，先明确新的稳定 ID 和迁移规则。

成长和本课保存失败会显示警告；损坏的成长记录不自动覆盖为零。数据只在当前设备浏览器保存，不上传、不登录。按当前需求暂不提供导入导出或跨设备同步，清除浏览器数据仍可能丢失进度。首版奖励数值是配置，不是学习能力量表。
